My first year was not clean progress; it was bugs, hackathons, bad assumptions, and a few systems that finally worked.

## Starting with MERN and realizing apps are more than UI

At first, building meant getting a page to look right. Then auth, database design, deployment, and API failures made it clear that full-stack work is mostly about the parts users do not see.

## The first time a backend bug blocked everything

One backend bug can make the entire product feel broken. Debugging those moments taught me to read logs slowly and stop guessing too early.

## Hackathons as pressure tests, not resume decorations

Hackathons forced decisions. I had to pick the stack, split work, ship features, and explain the system while it was still warm from the last bug fix.

## Learning AI integration without pretending it is magic

OpenAI API calls are not the product. The product is the workflow around them: inputs, scoring, explanations, caching, failures, and what the user sees when the model is unsure.

## Why I am going back to Java, DSA, and system design

Shipping projects taught me confidence. Fundamentals are teaching me discipline. I need both if I want to become a serious Software Engineer.

If you are early too, build things, write down the failures, and keep your fundamentals close.
