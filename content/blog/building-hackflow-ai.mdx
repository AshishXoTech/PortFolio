Building HackFlow AI started with a problem every hackathon organizer faces: evaluating dozens of project submissions manually is slow, inconsistent, and painful. We wanted to automate the evaluation pipeline without losing the nuance of human judgment.

## The Problem

Hackathon judges spend hours reviewing codebases, often skimming through repositories without understanding the actual engineering effort involved. We needed a system that could analyze GitHub repositories automatically and surface meaningful project insights.

## Architecture

We chose a microservice architecture to separate concerns:

- **Next.js 14** for the frontend with App Router and server components
- **Node.js + Prisma** for the main API layer with PostgreSQL
- **FastAPI** microservice for AI-powered repository analysis
- **JWT authentication** with role-based access for organizers and participants

The two backend services communicate through REST APIs. The FastAPI service handles the computationally intensive repository analysis while the Node.js service manages user authentication, leaderboards, and data persistence.

## Key Features

1. Automated GitHub repository analysis using AI
2. Real-time leaderboards with transparent scoring metrics
3. JWT-based authentication with role separation
4. Automated ranking that reduces manual review effort

## 48-Hour Sprint Lessons

Building under time pressure forces architectural clarity. We spent the first 4 hours designing the database schema and API contracts before writing any feature code. That upfront investment prevented integration issues when connecting the two backend services.

The most important lesson: microservices add complexity, but when each service has a clear boundary, parallel development becomes significantly faster. Two people can work on separate services without merge conflicts.

HackFlow AI won our university internal hackathon and demonstrated that AI-assisted evaluation can meaningfully reduce manual review overhead.
